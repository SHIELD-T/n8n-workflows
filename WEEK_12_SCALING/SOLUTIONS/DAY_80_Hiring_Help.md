## Model Answer

### Job Posting: n8n Workflow Developer (contract)

"We're looking for an experienced n8n developer to help build automation workflows for our clients."
**Requirements:** 2+ years n8n experience, API integration skills, JavaScript knowledge, problem-solving ability.
**Responsibilities:** build custom n8n workflows, integrate third-party APIs, debug/optimize, document technical solutions.
**Compensation:** $25-50/hr based on experience. **Timeline:** project-based contracts.

### Screening Criteria

- **Technical:** n8n workflow development, API integration, JavaScript/Node.js, database basics.
- **Soft skills:** communication, problem-solving, time management, client service.
- **Experience levels:** Junior (1-2 yrs), Mid (2-5 yrs), Senior (5+ yrs).

### Interview Process

30-minute video screening → n8n workflow challenge (build a small workflow live) → 1-hour team interview → reference check with a previous client.

### Role Card — What They Own vs. What Stays With You

**Owns:** end-to-end workflow builds assigned to them, technical documentation for their builds.
**Needs access to:** sandbox n8n instance, shared Notion workspace.
**Explicitly does NOT own:** client billing, master credentials, client strategy calls.

### Onboarding — Week 1

Day 1: welcome call and introductions. Day 2: company overview and tools setup (n8n instance access, Notion, Slack). Day 3: first (low-stakes) project assignment. Day 4: mentor pairing with Jordan. Day 5: first-week review.

### Team Communication & Task Management

Slack channels: #general, #projects, #technical, #random. Meetings: daily 15-min standup, weekly 1-hr team meeting, monthly 2-hr review. Task tracking: Notion, Projects → Tasks → Subtasks, clear ownership and deadlines. Performance metrics: project completion rate, client satisfaction score, technical quality, communication — reviewed monthly.
