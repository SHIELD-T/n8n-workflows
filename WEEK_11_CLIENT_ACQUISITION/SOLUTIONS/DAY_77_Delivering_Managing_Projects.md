## Model Answer

### Project Template — 3 Phases (Notion board)

1. **Discovery & Design** — requirements call, process map of current manual steps, credentials checklist for tools involved.
2. **Build & Test** — build the workflow, run 3 sandbox test cases, walk client through a screen-share review.
3. **Deploy & Train** — go live, 30-minute training call, deliver handover doc.

### Weekly Status Update (mock example — Coastal Air HVAC, fictional client)

- **Project overview:** Missed-call text-back + review automation build, Growth tier.
- **Completed this week:** Webhook trigger built and tested against 5 sample missed calls; SMS template drafted.
- **Planned next week:** Connect Airtable log, build review-request delay logic, client review call.
- **Risks/issues:** Client's SMS provider account not yet set up — blocking live testing until Wednesday.
- **Next milestone:** Client review call, Friday.

### Pre-Delivery Checklist
- [ ] Workflows tested end-to-end
- [ ] Documentation complete
- [ ] Training materials ready
- [ ] Client approval obtained

### Post-Delivery Checklist
- [ ] 30-day support window started
- [ ] Monitoring/alerts active
- [ ] Feedback survey sent
