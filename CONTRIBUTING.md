# Contributing to Automator Pro

Thanks for taking the time to help improve this course. This repo is course content for **Automator Pro: Master n8n + AI to Build Your Own Automation Business** — here's how to report problems or suggest fixes.

## Reporting an Issue

Before opening an issue, please **search existing issues** to see if it's already been reported.

If it's new, open a GitHub issue and include:

- **Broken video link** — which `DAY_XX` file or README it's in, the video URL, and what happens when you click it (removed, private, wrong content, etc.)
- **Broken workflow JSON** — which `EXAMPLES/*.json` file, the error message from n8n's import dialog, and your n8n version if relevant
- **Typo / factual error** — the file and line (or a short quote) so it's easy to find
- **Structural issue** (wrong day numbering, missing file, duplicate content) — which week/day, and what you expected instead

A minimal, specific report is far more useful than a general "this is broken."

## What We Can Accept

- Bug reports (broken links, invalid JSON, typos, numbering errors) — always welcome
- Small, targeted fixes via pull request (a corrected link, a fixed typo, a JSON syntax fix) — welcome
- Large content contributions (new daily lessons, new example workflows, rewritten weeks) — this is course content with a specific structure and voice, so large additions are **unlikely to be accepted** unless discussed with the maintainers first. Please open an issue to discuss before investing significant time in a big change.

## Ground Rules

- Be respectful and constructive — assume good faith
- Check existing issues and pull requests before opening new ones, to avoid duplicates
- Keep pull requests small and focused on one fix at a time
- Explain *why* a change is needed, not just *what* changed
